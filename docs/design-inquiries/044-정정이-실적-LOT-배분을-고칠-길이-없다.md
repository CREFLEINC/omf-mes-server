# 44. 정정이 실적↔LOT 배분을 고칠 길이 없다 — W/O 축 누계(042)와 LOT 축 누계가 정정 뒤 갈린다 · 어느 쪽이 「완료 판정」의 정본인가

| 칸 | 내용 |
|---|---|
| 걸리는 오퍼레이션 | `POST /production/production-results/{productionResultId}:correct` · `POST /trace/lots/{lotId}:complete` · `GET /trace/lots/{lotId}?withProgress=true` |
| 구현 상태 | **구현함(I-7 · `:correct` 는 배분을 만들지도 고치지도 않는다 · `Lot.progress`·`:complete` 는 원본 배분 그대로 `Σ production_result_lot_allocation.allocated_qty`)** |

| 되돌릴 때 | ① 「정정본이 배분을 싣는다」면 `ProductionResultCorrect.lotAllocations` 추가 + `:correct` 가 정정본 배분 행을 만들고 LOT 축 누계도 `ACTIVE_RESULT_WHERE` 로 원본 배분을 뺀다(`lot-progress.ts` where 한 줄) ② 「원본 배분을 비례로 복사하라」면 `:correct` 에 배분 복사 ~10줄 — 단 `Σ allocatedQty` 와 `goodQty` 의 관계를 계약이 안 적어(I-7 ⓖ) 비례 기준이 없다 ③ **042 가 「합」으로 뒤집히면 이 문의는 사라진다** |

## 무엇이 문제인가

`ProductionResultCorrect` 에 **`lotAllocations` 칸이 없다**(실측 · 등록 `ProductionResultCreate` 에는 있다). 양품을 정정해도 `production_result_lot_allocation` 은 원본 것만 남아 `P-02-06` 의 누적 양품(`Σ allocated_qty`)이 **그대로**다.

- W/O 축 누계(문의 **042** · 정정된 원본을 빼고 잎만)는 정정을 따라가고, LOT 축 누계(배분 합)는 안 따라간다 — **정정 뒤 두 누계가 갈린다.**
- 화면 증상: 양품을 **낮추는** 정정 뒤 `P-02-06` 의 달성률이 그대로라 작업자가 「완료 처리」를 누를 수 있다(`P-02-06` §5-3 표 — 완료 판정은 LOT 누적 양품 기준). 반대로 W/O 마감 3분류는 낮아진 값으로 `SHORT` 를 낸다.
- `achievementRate` 분모가 LOT/W-O 에서 다르다는 계약 ⚠(`plan.md` §7 이 I-7 에 배정)와 같은 자리에서 겹친다 — 분모뿐 아니라 **분자도** 정정 뒤 갈린다.

⚠ **042 에 종속.** 042 가 「합」으로 뒤집히면(정정본 = 증감 행) 정정본이 배분을 안 실어도 W/O 축이 같은 모양으로 남아 이 문의는 사라진다. 「잎만」이면 「LOT 축은 같은 규칙을 쓸 칸이 없다」가 된다 — 두 장으로 내되 상호참조.

## 지금 서버는

- `:correct` 는 정정본 행만 만든다 — 배분 행을 만들지도, 원본 배분을 복사·비례 조정하지도 않는다. `Σ allocatedQty` 와 `goodQty` 의 관계는 등록에서도 검사하지 않는다(I-7 ⓖ).
- `Lot.progress`(`withProgress=true`)·`:complete` 의 누적 양품은 원본 배분 그대로 `SUM(allocated_qty) WHERE lot_id` — 정정 축을 안 본다. 완료 판정(미달 여부 · `completionVarianceReasonCode` 필수)도 그 값으로 한다.

흔적: `production-result-correct.service.ts` 머리 주석 ⌜배분을 만들지도 복사하지도 않는다 — 계약 본문에 칸이 없고, 복사하면 `:complete` 의 누적 양품이 두 배가 된다(§5-6 · 문의 044)⌝ · 단위 `정정 — 배분을 만들지 않는다` · `lot-progress.ts` 는 배분 합만 본다(정정 축 없음 — 리뷰 #242 Minor ① · 「알려둘 것」). ⚠ `:correct` 뒤 `Lot.progress` 를 단언하는 e2e 는 없다(후속 후보).
