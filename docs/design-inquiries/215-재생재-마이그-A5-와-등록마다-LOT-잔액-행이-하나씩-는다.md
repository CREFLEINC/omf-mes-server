# 215. 재생재 — 마이그 **A5** 의 범위, 그리고 **등록마다 LOT·잔액 행이 하나씩 는다**

**구분: 통보**(회신을 기다리지 않는다)

| 칸 | 내용 |
|---|---|
| 걸리는 오퍼레이션 | `POST /logistics/recycle-entries`(I-17) |
| 구현 상태 | 마이그 A5 는 **이 슬라이스가 낸다**(PR ① 선행 커밋) |
| 판정 | §2 **2단계 기준 3**(스키마를 «덜» 늘리는 쪽) · **기준 4**(값을 조용히 도출하지 않는 쪽) |

## ⓐ 마이그 A5 — 추가 2 + **완화 2** · 삭제 0 · 백필 0

| 무엇 | 왜 |
|---|---|
| `ADD warehouse_id bigint NULL` + FK → `mdm.warehouse` | 계약 `RecycleEntryCreate.warehouseId` 가 **required** 인데 칸이 없었다 |
| `ADD remarks text NULL` | 계약 `RecycleEntryCreate.remarks` |
| ⭐ `ALTER source_document_type_code DROP NOT NULL` | ⭐ `ALTER source_document_id DROP NOT NULL` |

⭐ **완화 둘의 이유** — 계약 `RecycleEntryCreate` 의 프로퍼티 **7개(required 6)** 에 **원천 문서 축이 0개**다
(`itemId`·`quantity`·`warehouseId`·`locationId`·`businessDate`·`occurredAt`·`remarks`). 분쇄재는 **어느 전표에서 오지 않는다** —
현장이 보고 등록한다. 그런데 물리가 두 칸을 NOT NULL 로 요구해, 값을 **지어내야** 통과한다(기준 4 위반).
⇒ **푼다.** 공유계약 A-10(다형 참조)은 「가리킬 것이 있을 때」의 규약이고 재생재는 가리킬 것이 없다.

⛔ **`ix_recycle_entry_source` 는 그대로 둔다** — 원천이 있는 다른 쓰기가 나중에 생길 수 있고, 인덱스는 NULL 행을 안 담는다.
⛔ **새 인덱스 0** · **삭제 0** · **백필 0**(표가 0행이다).

⚠ **새 FK 가 하나 생긴다** ⇒ `WAREHOUSE_REFERRERS` **16 → 17행**을 **같은 PR 에서** 채운다
(README §6-4 일반화 — 안 채우면 `test/mdm-warehouse.e2e-spec.ts` 가 `main` 에서 빨개진다).

## ⓑ ⭐ 등록마다 **LOT 행과 잔액 행이 각각 하나씩** 는다 — 합쳐지지 않는다

계약 `RecycleEntryCreate` 에 **`lotId` 가 없다.** LOT 번호는 **서버가 매긴다**(C-2 · 화면이 「번호는 저장 후 정해집니다」를 먼저 말한다).
⇒ 같은 품목·같은 위치로 열 번 등록하면 **LOT 이 열 개** 난다.

그리고 `uq_inventory_balance_dim` 이 **`lot_id` 를 포함**한다 ⇒ 잔액도 **합산되지 않고 행이 열 개** 선다.

| 기대했던 모양 | 실제 |
|---|---|
| 같은 (품목·위치)면 잔액 한 행이 누적 | **LOT 축이 갈려 행이 따로 선다** |

⛔ **서버가 합치지 않는다** — 합치려면 「기존 LOT 에 더한다」가 필요한데 계약이 `lotId` 를 안 주고, LOT 마다
제조 시각·계보가 달라 합치면 추적성이 깨진다(기준 4).

## 📨 알려 드리는 것

**⓵ 재생재를 «기존 LOT 에 합치는» 길이 없습니다.** 현장이 같은 분쇄재를 하루에 여러 번 등록하면 LOT·잔액 행이
그만큼 늡니다. 화면 `M-01-12` 가 그 목록을 어떻게 보여 줄지(묶어 보이나, 낱낱이 보이나) 정해 주시면 좋겠습니다.

**⓶ `remarks` 를 저장하지만 되읽을 경로가 0건입니다.** 계약 응답 `RecycleEntry` **프로퍼티 10개에 `remarks` 가 없고**,
이 오퍼레이션 말고 `recycle_entry` 를 읽는 오퍼레이션이 **0건**입니다 ⇒ 쓰고 나면 **영영 못 봅니다.**
조회 오퍼레이션이 생길 계획이면 알려 주십시오.
