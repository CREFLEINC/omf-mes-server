결손/과거OK·NG는 INTERNAL_ERROR로 명시 실패하며 정상200 지원으로 세지 않는다. 목록에서 숨기거나 total에서 빼지 않는다. 불일치가 있는 환경의 정상서비스 배포는 별도 유보하되 새데이터용 구현은 진행한다. PUT/start의 응답 실패도 상태·감사·version·멱등이 함께 롤백돼야 한다.

I-30 ① 독립 코드 리뷰 보완(R-15): 기간 비교의 SQL UNKNOWN이 inspected_at NULL을 숨기는 누락을 확인했다. 날짜 외 같은 관계 필터의 후보에 NULL 시각이 있으면 기간 소속을 알 수 없으므로 metadata 조회에서 INTERNAL_ERROR로 명시 실패한다. 가짜 날짜나 count 포함을 만들지 않는다. 무관한 설비/유형/판정/기발행 후보는 제외하며 무기간 미발행의 NULLS LAST·역전 빈집합은 기존 판정을 유지한다.
