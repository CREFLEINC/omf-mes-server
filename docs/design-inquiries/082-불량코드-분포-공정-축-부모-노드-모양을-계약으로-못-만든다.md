# 82. 불량코드 분포 — 공정 축(기본값)의 부모 노드를 `DefectDistributionNode` 로 만들 수 없다 (R-14)

| 칸 | 내용 |
|---|---|
| **구분** | ⭐ **통보**(§2 1-1 — 2026-09-08 규칙) · 회신을 기다리지 않는다 |
| 걸리는 오퍼레이션 | `GET /quality/defect-records/distribution` — `groupBy=occurrenceProcess`(기본값)·`detectionProcess` |
| 구현 상태 | **구현함 — 공정 축은 부모(공정) 노드를 `nodes` 에 넣지 않는다. 결함코드 자식 노드만 평평히 낸다** |
| 판정 | `coverage-100/README.md` §2 1-1(본질 아님 — 응답 모양 문제일 뿐 업무 규칙·추적성·원장·회계 기간이 아니다) ⇒ **통보**. 모양은 §2 2단계 기준 4(값을 조용히 지어내지 않는 쪽)로 골랐다 |

## 결정

`groupBy=occurrenceProcess`·`detectionProcess`(공정 축)에서는 **부모(공정) 노드를 만들지 않는다.**
`nodes` 는 (공정, 결함코드) 쌍마다 결함코드 자식 노드 하나씩만 담고, 공정 맥락은 `label` 에
`"{공정명} · {결함코드명}"` 으로 묶어 남긴다. `parentDefectCodeId` 는 생략한다(부모가 없다).
`groupBy=defectCode` 는 `defect_code.parent_defect_code_id` 가 실물 2계층이라 부모·자식을 그대로 낸다.
흔적: `src/quality/defect/defect-distribution.service.ts` `byProcess()` · `// 결정 — 통보 082`.

## 왜

- 계약 `DefectDistributionNode` 는 `defectCodeId`·`parentDefectCodeId`·`label`·`recordCount`·`defectQty`·
  `share`·`duplicateRisk` 7칸뿐이다 — **공정을 가리키는 칸이 0개**이고 `defectCodeId` 는 **required** 다.
- `groupBy` 설명(「occurrenceProcess 로 묶어야 개선 대상이 나온다」)과 계약 기본값 후보(`occurrenceProcess`)를
  같이 읽으면, «부모가 공정인» 2계층을 기대한 것으로 읽힌다. 그런데 그 부모 노드에 채울 `defectCodeId` 가
  없다 — 공정은 결함코드가 아니다.
- 검토한 세 갈래(§4-4 R-14):
  - **ⓐ 부모(공정) 노드를 안 넣고 자식만 평평히 낸다** — 채택. `defectCodeId`·`label`·`recordCount`·
    `defectQty` 전부 실제 값이고 계약 required 를 100% 지킨다. 잃는 것은 "부모 노드 객체 하나"뿐이고
    그 정보(어느 공정인지)는 `label` 에 남는다.
  - **ⓑ 부모 노드의 `defectCodeId` 에 공정 id 를 넣는다** — 탈락. `defectCodeId` 라는 이름이 결함코드를
    가리키는데 실제로 공정 id 를 담으면 **칸의 뜻이 바뀐다**(화면이 그 값으로 결함코드를 다시 조회하면
    엉뚱한 코드가 나온다).
  - **ⓒ 부모 노드는 만들되 `defectCodeId` 를 생략한다** — 탈락. required 를 명시적으로 어기는 응답을
    만드는 쪽보다, 애초에 required 를 어길 필요가 없는 ⓐ 가 §2 2단계 기준 4(값을 조용히 지어내지/생략하지
    않는 쪽)에 더 가깝다.
- 「본질 아님」인 이유 — 이 판정은 업무 규칙·추적성(LOT 계보)·재고 원장·회계 기간 중 어느 것도 바꾸지
  않는다. 조회 응답의 **모양**만 정하는 문제라 §2 1-1 표에서 「정하고 통보」 칸에 든다.

## 설계팀이 답을 줄 때 필요한 것 하나

> **공정 축 분포에서 「부모(공정) 그룹」을 화면이 정말 필요로 하는가, 필요하다면 `DefectDistributionNode`
> 에 공정을 가리키는 칸을 추가할 것인가**

그 한 줄이면 부모 노드를 다시 채운다. 그때까지는 `label` 에 공정명을 묶어 정보를 유지한다.
