## 이미 정해져 다시 묻지 않는 규칙

- 실제 조업은 work_session 구간Σ, 계획 장비배정/인원수를 JOIN해 증폭하지 않는다. 설비미지정 실제 세션도 조업합/별도건수에는 포함하고 설비별묶음에서 제외한다.
- 실제 비가동은 같은 설비 닫힌 구간 union, 열린 비가동은 시간 제외·원본건수. 다른 설비 시간은 각각 더하며 맞닿음은겹침0, 겹침건수는 참여원본행 수다.
- W-05-08 §8-3의 minor는 **공장 단위면 충분**, 제공plant→BU→ALL만 평가하고 ITEM/PROCESS를 추정하지 않는다. 미설정만5분, 설정0/음수를5로 바꾸지 않는다. duration<threshold가minor, actual에포함·일반사유와별도줄이다.
- 폐지사유는 미분류표시+원본code를 보존하고 UNKNOWN같은코드0. reasonnull은108의required결손과다르다.
- 사유별raw시간합은 전체union보다 커질 수 있고 비율은 임의100%clamp하지 않는다. operating0이면availabilitynull이다.

**위 조건별 집계 의미 또는 지원하지 않을 때의 명시적 거부를 확인해 달라.** 모든 조건이 끝나야만 정상구간을 열 수 있다는 요구가 아니다. 111의 정상 원천이 먼저 해소되면 루틴의②명시거부·④조용한도출금지 기준으로 각 경계를 재판정한다. 서버수신now·임의기본교대·전체0·상시선택키생략으로빈칸을숨기지않는다.

근거는 고정계약 equipment-05설비툴.json:4476 이후와 W-05-08 §5~§8, I-32 R8~R12·§7·§9다. 요약→목록에없는plant/group질의를추가하는문제는110으로인계한다. 설계팀외부등록0이며실제구현/게이트성공을주장하지않는다.
