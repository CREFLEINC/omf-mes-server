# 39. 마감 전 게이트 셋(POP 버퍼 미동기 실적 · 미종료 홀드 · 실적 완결성)을 서버가 판정할 수단이 없다 — 계약 스스로 ⌜서버가 단말 버퍼를 볼 수단이 계약에 없다⌝ 라 적었다

| 칸 | 내용 |
|---|---|
| 걸리는 오퍼레이션 | `POST /production/work-orders/{id}:close` |
| 구현 상태 | **구현 예정(I-6 · 셋 중 아무 게이트도 만들지 않는다 · 계약이 판정 수단을 준 `OPEN_SESSION_EXISTS`(409)만 실행)** |
| 판정 | `coverage-100/README.md` §2 1단계 **본길**(모든 마감이 지난다) → 계약도 침묵(x-internal-note ⌜✓확정 2026-07-14 … ⚠ 서버가 단말 버퍼를 볼 수단이 계약에 없다 — 게이트를 무엇으로 판정하는지가 열려 있다⌝) ⇒ 판정을 만들지 않는다 |
| 되돌릴 때 | 게이트마다 판정 축이 오면 `:close` 순서의 「열린 세션」 검사 옆에 검사 한 줄씩 + 409 `code` 값(계약 enum 5에 맞는 값이 있는지도 같이 답해 달라). 둘째(미종료 홀드)는 문의 035 의 구간 표가 서야 셀 수 있다 |

## 무엇이 문제인가

계약 `:close` 의 x-internal-note 가 마감 전 게이트 **셋**을 확정(2026-07-14)했다 — ① POP 버퍼에 아직 동기되지 않은 실적이 있으면 마감 불가 ② 미종료 홀드가 있으면 불가 ③ 실적 완결성. 그리고 같은 노트가 바로 ⌜서버가 단말 버퍼를 볼 수단이 계약에 없다⌝ 라 적었다. 실측:

- ① 단말 버퍼는 서버 표에 없다. 실적 동기 경로(`production-results`)가 「보낸 것」만 남기고 「아직 안 보낸 것」은 단말에만 있다 — 서버가 셀 수 없다.
- ② 미종료 홀드 — W/O 층 중단 구간 표가 없다(문의 035 ⓑ 와 같은 뿌리). `status_code='SUSPENDED'` 로 근사할 수는 있으나 `:close` 의 `from` 이 `COMPLETED` 뿐이라 `SUSPENDED` 는 전이표가 이미 400 으로 막는다 — 게이트로서는 공집합이다.
- ③ 「실적 완결성」은 정의가 없다(수량 일치인가 · 세션 전건 종료인가 · 검사 완료인가).

**부르는 화면이 0건**이라 이 게이트가 설 자리는 서버 판정뿐이다 — 「화면이 없다」는 게이트가 없다는 뜻이 아니라 판정 수단이 없다는 우리 물음의 근거다.

## 지금 서버는

`:close` = If-Match → 전이(`COMPLETED` → `CLOSED`) → **열린 세션이 있으면 409 `{code:'OPEN_SESSION_EXISTS'}`**(계약이 판정 수단을 준 유일한 게이트) → 3분류 판정(정상·미달·초과 · 허용 오차 0) → 본문 4규칙 → ERP 아웃박스 적재. 셋 중 어느 게이트도 검사하지 않는다. 승인 게이트도 없다(계약이 요구하지 않는다).

흔적: `:close` 주석 `// 마감 전 게이트 셋(버퍼·홀드·완결성)은 판정 수단이 없다 — OPEN_SESSION_EXISTS 만 본다(문의 039)` · 단위 테스트 `close — 열린 세션만 막는다(다른 게이트는 없다)`.
