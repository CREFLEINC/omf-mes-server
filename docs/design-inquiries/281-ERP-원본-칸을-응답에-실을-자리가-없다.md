# 281. ERP 에서 받아 저장한 **원본 칸을 응답에 실을 자리가 없습니다**

**구분: 질의**(어느 칸을 화면에 보일지는 설계가 정한다 · 서버는 저장만 했다)

| 칸 | 내용 |
|---|---|
| 걸리는 오퍼레이션 | **횡단** — `GET /mdm/items` · `GET /planning/boms/{bomId}/components` · `GET /logistics/purchase-orders` · `GET /logistics/sales-orders` · `GET /planning/production-orders` · `PUT /logistics/purchase-orders/{purchaseOrderId}`(+`/lines`) |
| 구현 상태 | 아래 칸을 저장한다. 응답에는 싣지 않는다. ERP 발주 수정은 400 으로 막는다(선행 P-64) |
| 판정 | ERP 로 되돌려 보낼 값과 업무 뜻이 있는 값은 온 그대로 담는다 · ERP 발주는 MES 에서 고치지 않는다 — 사용자 결정 2026-10-20 |

## 저장한 칸

| 개체 | 칸 | ERP 원본 | 왜 담나 |
|---|---|---|---|
| 품목 | `erp_spec` | `SPEC` | 규격. 5,060건 채워짐 |
| 품목 | `erp_item_group_code` | `ITEM_GROUP_CD` | 품목그룹. 9,635건 채워짐 |
| BOM 구성품 | `erp_child_item_seq` | `CHILD_ITEM_SEQ` | ERP 업무 키. 0 이 30건이라 `sequenceNo`(1 이상)와 따로 둔다 |
| 발주 | `erp_order_type_code` | `PO_TYPE_CD` | 위탁가공(SC)·임가공(FCO) 구분 |
| 발주 | `erp_purchase_group_code` | `PUR_GRP_CD` | 구매입고 송신 필수 |
| 발주 | `erp_io_type_code` | `IO_TYPE_CD` | 구매입고 송신 |
| 발주 라인 | `erp_storage_location_code` · `cancelled_at` | `SL_CD` · `CREATE_TYPE=C` | 입고창고(송신 필수) · 라인 취소 |
| 수주 | `erp_order_type_code` | `SO_TYPE_CD` | 반품(RFOC)·무상출고(FOC) 구분 |
| 수주 | `erp_movement_type_code` | `MOV_TYPE` | 제품출하 송신 필수 |
| 수주 | `erp_sales_group_code` | `SALES_GRP_CD` | 영업그룹 |
| 수주 라인 | `erp_storage_location_code` · `cancelled_at` | `SL_CD` · `CREATE_TYPE=C` | 출고창고(송신 필수) · 라인 취소 |
| ERP W/O | `erp_operation_no` | `OPR_NO` | 생산입고 송신 필수. `010`·`1` 이 섞여 온 그대로 |
| ERP W/O | `erp_storage_location_code` | `SL_CD` | 입고창고 |
| ERP W/O | `erp_rework_flag` | `RE_WORK_FLG` | 재작업 여부 |

코드 칸의 이름(`_NM`)은 담지 않는다 — ERP 공통코드(`ORDER_TYPE`·`SO_TYPE`·`SALE_GROUP`·`PUR_GROUP`·`SL_TYPE`)가 시스템 소유 코드 그룹으로 들어와 있다.

## 📨 요청

1. 위 칸 중 화면에 보일 것을 골라 응답 필드를 더해 주십시오.
2. 라인 취소(`cancelled_at`)를 응답에 실을지, 취소된 라인으로 입고·출하를 막을지 정해 주십시오. 서버는 지금 막지 않는다.
3. ERP 에서 받은 발주(`erpPurchaseOrderNo` 가 있다)의 헤더 수정·라인 치환을 서버가 400 `STATE_LOCKED` 로 막았다. 화면이 `erpPurchaseOrderNo` 로 수정 버튼을 잠그면 되는지, 잠김을 알리는 칸(`editability` 등)을 더할지 정해 주십시오.
