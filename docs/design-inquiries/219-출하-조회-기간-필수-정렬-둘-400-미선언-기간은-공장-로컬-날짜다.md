## 정한 것 다섯

| # | 자리 | 정한 것 | 근거 | 되돌릴 때 |
|:-:|---|---|---|---|
| ⓐ | `shipDateFrom` 없음 | **400 `REQUIRED`** | 질의 설명 「필수」 + 오퍼레이션 설명 「기간 필수(L-3)」 — ⛔ 그런데 **400 이 미선언**이다 | 「없으면 전건」 — `WHERE` 한 줄 + e2e 두 건 |
| ⓑ | 기간이 «어느 칸»인가 | **`shipped_at`** | `shipment` 의 날짜 칸 다섯 중 전건 의미를 갖는 것이 이것뿐이다 — `created_at` 은 업무 사실이 아니고, `confirmed_at`·`cancelled_at` 은 일부 행만, `loaded_at` 은 「상차」다. `ShipmentCreate.occurredAt`(「실물이 나간 시각」)이 이 칸에 든다 | 칸 이름 두 곳 |
| ⓒ | `sort` | **`shippedAt`(기본) · `shipmentNo` 둘** · 밖은 **400 `INVALID`** · 기본 = `shipped_at ASC, shipment_id ASC` | 계약이 키 «목록»을 안 주고 「경과일 긴 순이 기본이다」 한 문장뿐이다(= 오래된 것이 위). ⛔ `customerId` 는 `shipment` 의 칸이 아니라 출하작업지시 조인이라 정렬 축으로 열지 않는다 | `SORT_COLUMNS` 한 줄 |
| ⓓ | ⚠ `W-04-12` 첫 진입 | 기간 없는 요청은 **400** 이다 ⇒ **화면이 첫 진입에 기본 기간을 실어야 목록이 열린다** | ⓐ 의 필연 — 통보 201 의 형제들과 같다 | ⓐ 와 같다 |
| ⓔ | ⭐ 날짜 경계 | **출하 창고가 속한 공장의 로컬 날짜** — `shipped_at >= (from 의 공장 자정)` · `shipped_at < (to 다음 날의 공장 자정)` | `shipped_at` 은 `timestamptz` 이고 DB 는 UTC 다. 날짜 그대로 견주면 **UTC 자정**이 경계가 되어 하노이(UTC+7) 00:00~07:00 출하가 **전날**로 간다 | `plantMidnightSql()` 본문 한 줄 |

### ⓔ 를 예로 — 픽스처 `B`(e2e L-3)

| `shipped_at` | 하노이(공장 `Asia/Ho_Chi_Minh`) | `shipDateFrom=To=2026-08-21` | `…=2026-08-22` |
|---|---|:-:|:-:|
| `2026-08-21T23:30Z` | **22일** 06:30 | ✕ | ⭕ |

- ⛔ **요청 하나를 시간대 하나로 접지 않는다** — `warehouseId` 가 선택이라 한 목록에 여러 공장이 섞일 수 있다 ⇒ **행마다** 창고 → 공장 → `timezone_code` 로 푼다(선례 `inventory-balance.service.ts:145-176`).
- ⚠ **구현 중 정정** — 처음 구현은 UTC 자정과 견줬다. 계획서(R-16 ⓓ)가 「공장 시간대로 푼다」로 정했는데 구현이 미뤘고, 리뷰 단계에서 찾아 고쳤다. 변이 넷(UTC 자정 · 시작만 UTC · 끝만 UTC · 끝 `+1` 제거)이 전부 e2e L-3 에서 죽는다.

### 그 밖에 알려 두는 것
- `shipped_at` 이 **NULL 인 행은 목록에 영영 안 나온다** — 기간이 필수라 3값 논리로 떨어진다(e2e L-13). 우리 API 로 만든 출하는 `occurredAt` 이 required 라 늘 값이 있고, 이 갈래는 그 «이전» 행에만 성립한다. 그래서 정렬에 `NULLS LAST` 를 붙이지 않았다(도달 불가).
- 목록 응답에는 `lines` 키가 **없다** — `Shipment.required` 에 없고, 상세 설명만 「라인과 LOT 배분을 함께 내린다」다.

## 📨 청하는 것
1. `GET /logistics/shipments` 에 **400**(`REQUIRED` · `INVALID`)을 선언해 주십시오 — 통보 201 의 넷과 한 번에.
2. `shipDateFrom`·`shipDateTo` 설명에 「**`shippedAt` 의 공장 로컬 날짜** · 끝 날짜 포함」 한 줄.
3. `sort` 에 키 목록(enum) — 오늘은 `shippedAt` · `shipmentNo`.
4. `W-04-12`(그리고 같은 오퍼레이션을 쓰는 `W-04-02` · `W-04-04`)의 **기본 기간**을 화면 문서에 적어 주십시오.
