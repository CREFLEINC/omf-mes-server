# 40. 긴급 발행(`W-02-07` · `productionPlanId` 빈 `POST`)이 만들 내부 P/O 의 공장·사업부를 풀 값이 어디에도 없다 — `W-02-07` §8 미결 1 ①안은 그대로는 성립하지 않는다

| 칸 | 내용 |
|---|---|
| 걸리는 오퍼레이션 | `POST /production/work-orders` (`productionPlanId` 를 비운 호출) |
| 구현 상태 | **구현 예정(I-6 · `productionPlanId` 가 비면 400 `REQUIRED`(field=`productionPlanId`) · 내부 P/O·계획 생성은 답 뒤 별도 PR — I-24 와 같은 자리)** |
| 판정 | `coverage-100/README.md` §2 1단계 가장자리(계획을 비운 호출만) → 2단계 **기준 2(거부하는 쪽)** — 「공장이 하나뿐이면 그것」은 기준 4 가 금하는 조용한 도출이다 |
| 되돌릴 때 | 공장을 실을 자리가 정해지면(요청 칸 · 헤더 · 사번→소속) 400 한 줄을 빼고 보류한 `internal-plan.ts`(내부 P/O + 계획 + 기본 BOM 선별 + `PP`/`PO` 채번)를 짓는다 — I-6.md §7-1 에 물리 필수 칸 실측이 남아 있다 |

## 무엇이 문제인가

`W-02-07` §5-2 ①안(2026-08-26 확정)은 ⌜계획 없이 W/O 를 만들면 서버가 내부 P/O 와 계획을 함께 만든다⌝ 다. 그 P/O 는 `planning.production_order.plant_id`·`business_unit_id` 가 **NOT NULL** 이다. 그런데 그 값을 어디서도 받을 수 없다(전수 실측):

- `WorkOrderCreate` 11칸(`dueDate`·`itemId`·`orderQty`·`plannedEndAt`·`plannedStartAt`·`priorityNo`·`productionPlanId`·`remarks`·`routingOperationId`·`uomId`·`workOrderTypeCode`)에 **`plantId`·`productionLineId`·`defaultWipLocationId` 가 없다**. required 는 `routingOperationId`·`itemId`·`orderQty`·`uomId` 넷.
- `mdm.routing`·`routing_operation`·`item`·`uom` 어디에도 `plant_id` 가 없다. `production_line.plant_id` 는 있으나 `W-02-07` §4-A 가 라인·WIP 를 「전부 비운다」.
- 계약 사본 전체의 요청 헤더는 `X-Worker-No` 하나뿐 — 공장 컨텍스트 헤더가 없다. 사번→소속 공장 매핑도 계약에 없다.
- `plant.business_unit_id` 도 nullable 이라 공장이 풀려도 사업부가 한 번 더 빈다.

계획이 있는 호출은 `production_plan → production_order.plant_id` 로 한 축에서 풀린다. 계획이 없는 호출만 빈다 — 긴급 경로가 **언제나** 빈다.

## 지금 서버는

- `productionPlanId` 가 비면 400 `REQUIRED`(field=`productionPlanId` · 메시지 「긴급 발행 경로는 공장 컨텍스트 확정(문의 040) 뒤 연다」). 계획이 있으면 계약대로 만든다(`status_code='PLANNED'` · `work_order_type_code` 미지정 시 `'NORMAL'` 명시 · 201 + ETag).
- 보류: `internal-plan.ts` · 기본 BOM 선별(`bom WHERE parent_item_id AND is_default` — `BOM_STATUS` 그룹이 없어 상태 조건 없음 · 후보 0 또는 2+ 면 400) · `plan_no`·`production_order_no` 채번(`DEFAULT_PREFIX` `PP`·`PO`) · 문의 14 표의 두 행. 전부 답 뒤 PR.
- `dueDate` 는 내부 P/O 에 실릴 칸이라 계획이 있는 호출에서는 버려진다(「알려둘 것」).

흔적: `POST` 주석 `// 계획 없는 POST 는 공장·사업부를 풀 값이 없다 — 400 (문의 040 · internal-plan.ts 보류)` · e2e `POST — productionPlanId 가 없으면 400 REQUIRED`.
