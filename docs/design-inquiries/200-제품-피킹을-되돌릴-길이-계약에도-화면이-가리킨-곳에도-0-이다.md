# 200. 제품 피킹을 **되돌릴 길이 계약에 0건**이고, ⭐ **화면이 가리킨 곳에도 0건**이다

**구분: 통보**(회신을 기다리지 않는다) · ⭐ **통보 071·180 과 «같은 모양»입니다 — 묶어 보십시오**

| 칸 | 내용 |
|---|---|
| 걸리는 오퍼레이션 | `POST /logistics/shipment-requests/{id}/lines/{lineId}:pick`(되돌림 없음) · `POST /logistics/shipment-requests`(편성 취소 없음) |
| 구현 상태 | **구현 예정(I-22)** — 되돌리는 경로를 **만들지 않는다** |
| 판정 | §2 **1단계 본길** → 계약에 오퍼레이션이 0건이라 **지어내지 않는다**(기준 4) |
| 되돌릴 때 | 오퍼레이션이 생기면 서비스 하나(코어는 이미 있습니다 — 아래) |

## 잘못 집으면 풀 길이 없다

| 자리 | 실측 |
|---|---|
| `:unpick` 류 오퍼레이션 | **0건** |
| `:pick` 으로 0 을 보내 지우기 | ⛔ 불가 — 계약이 「이번에 집은 수량. **0 보다 커야 한다**」 · 누적이라 음수도 없다 |
| 출하작업지시 **편성 취소** | ⛔ 0건 — 계약이 「⛔ **편성 취소를 두지 않는다** — 출하작업지시 취소는 **범위 밖**」이라 명시 |
| 작업지시 **수정**(`PUT`) | 0건 |

## ⭐ 화면이 가리킨 곳에도 없습니다

`M-04-01` §5-7 액션 표: 「확정 후 되돌리기 \| ⛔ **두지 않는다 — 예약이 소진된다.** 되돌림은 **`W-01-13` 계열**」.

**그 `W-01-13` 이 04 를 명시적으로 제외합니다** — §1 범위: 「**01 도메인 문서 9종** … ⛔ **출하 취소(FR-IM-079)는 04 도메인**」.
그리고 취소 가능 문서 유형은 `CD-CANCELABLE-DOCUMENT-TYPE` **3종(입하·입고·출고)**뿐이라 **피킹은 01 에서도 못 되돌립니다.**

⇒ **「계약에 0건」이 아니라 「화면이 존재하지 않는 경로를 가리킨다」**입니다.

## ⇒ 우리가 정한 것

- 되돌리는 경로를 **만들지 않습니다.**
- ⭐ **코어는 이미 준비돼 있습니다** — `:pick` 을 「걸고 곧바로 푸는」 안으로 구현하므로, 되돌림이 필요해지면 기존 `posting.pick()` 의 **Δ<0 갈래**가 그대로 감당합니다(`picked_qty ≥ −Δ`·`consumed_qty ≥ −Δ` 하한이 이미 있습니다). **새 코어를 지을 필요가 없습니다.**
- 그때까지 잘못 집은 예약은 **출하(I-23)로 소진되기 전에는 못 풉니다.**

## 📨 알려 드리는 것

1. **제품 피킹을 되돌리는 오퍼레이션을 열어 주십시오** — `:unpick` 이든 `:pick` 의 0 허용이든 좋습니다. 현장 스캔은 오독이 납니다.
2. ⭐ **`M-04-01` §5-7 의 「되돌림은 `W-01-13` 계열」 문장을 고쳐 주십시오.** `W-01-13` §1 이 04 를 제외하고 취소 3종에 피킹이 없습니다.
3. **편성 취소가 정말 범위 밖입니까?** 잘못 편성한 작업지시를 지울 길도 지금은 0건입니다.

⭐ 이것은 **통보 071**(C9 로 걸린 보류를 풀 길이 0)·**180**(폐기 LOT 을 되돌릴 길이 0)과 같은 모양이고, 여기는 한 술 더 떠 **화면이 없는 경로를 가리킵니다.**

## 🔎 이 통보가 «흡수»한 것 (3관점 재검토 · 2026-09-09)

| 어디서 왔나 | 무엇 |
|---|---|
| **UI/UX 관점**(§4 #2 · 후보 **δ**) | ⭐⭐ **되돌림 경로가 «막다른 길»임을 찾았다.** `M-04-01` §5-7 이 「되돌림은 **`W-01-13` 계열**」이라 가리켰는데 **`W-01-13` §1 이 「출하 취소(FR-IM-079)는 04 도메인」으로 04 를 명시 제외**하고, 취소 가능 유형은 **입하·입고·출고 3종**뿐이라 피킹은 01 에서도 못 되돌린다 ⇒ **「계약에 0건」이 아니라 「화면이 존재하지 않는 경로를 가리킨다」** · I-21 통보 **071·180** 과 같은 모양 |
| **UI/UX 관점** | ⚠ 그 문장의 근거(「예약이 소진된다」)도 **초판의 ⓐ안에서는 거짓**이었다(예약이 열린 채 남는다) — ⓒ안으로 바뀌며 그 문장은 참이 됐다 |
| **통합 관점** | ⭐ **되돌림 코어는 이미 있다** — `pick()` 의 Δ<0 갈래(`reservation-qty.ts:80-81·109-112`)가 그대로 감당한다 |

⇒ 초판 후보 **K**(「계약에 0건」)에 uiux **δ** 를 합쳐 근거가 한 단계 세졌다.
