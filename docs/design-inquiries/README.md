# 설계 검토 요청서 — 단건 모음

커버리지 100 루틴(`../coverage-100/README.md`) 중 발생 시점마다 **한 건 한 파일**로 쓴다.
번호는 이미 보낸 1~15번(`~/omf-design-requests/설계-문의-2026-09-0*.md`)에 이어 **16번부터**.
루틴이 끝나면 한 파일로 묶어 사용자를 통해 설계팀에 전달한다(직접 소통 금지).

## ⭐ 2026-09-08 — 이 폴더에 «두 가지»가 들어온다

사용자 지시로 판정 규칙이 바뀌었다(`coverage-100/README.md` **§2 1-1단계**). **기본값은 「정하고 통보」**이고,
**MES 본질 × 바꾸는 비용 높음** 둘 다에 걸릴 때만 묻는다.

| 구분 | 뜻 | 회신 |
|---|---|---|
| **질의** | 우리가 정하면 안 되는 것 — 답이 와야 그 자리가 선다 | **기다린다**(그 자리만 미루고 나머지는 진행) |
| **통보** | 우리가 정했다. 알려 두는 것 | **기다리지 않는다** |
